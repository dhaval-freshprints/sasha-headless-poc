3. Why Sasha cannot do it today

  1. Fact navigate refuses the host: config.ALLOWED_HOSTS is the FP host, the login host and www.freshprints.com (config.py lines 28-35). dt-qa.internal-fp.com is not in it.
  2. Fact The controls are role-less DIVs, so find/read_page return nothing for "Add Text", "Change Product", "Screen Print", "Switch to This", the colour tiles. The model would have to screenshot and click coordinates for every one of them.
  3. Fact hover returns only "Hovered ref_N." (toolset_executor.py line 349-355); tooltip text is not reported, so colour names are unreadable without a screenshot per tile.
  4. Fact form_input on a combobox waits 8 x 300 ms for options (toolset_executor.py _wait_for_options); the Deal box needs about 5 s and shows "Loading…" first.
  5. Fact playbook.md line 103 says "Don't use the Design Tool for this." workplace.md line 33 says the Design Tool "is a canvas editor. The proof's text cannot be read from the tree there." Both are true today and both steer away.

4c. playbook.md (judgment) — needs your decision

Line 103 currently routes every new proof to the wizard. The Design Tool route has to be chosen by rule, and the rule is judgment, not mechanics. Proposal:

  • Words only (a name, a slogan, a date), a font or a colour, a placement the client named: Design Tool. The proof is Done at once and the client can see it in the same reply.
  • Artwork, a logo, an uploaded file, a school's marks, or anything Sasha would have to draw: the wizard, so the art team makes it.
  • In the Save menu, Send a Copy to Client is No. Sasha writes the reply herself.
  • Same rule as before: open the deal and see the proof before saying a mockup is ready. Now it can say "here is the mockup" instead of "a mockup is on the way".
  • Revisions on a Design Tool proof go through "Revise in Design Tool", not the revision form, because the words are on the canvas, not in the description.
Two things to confirm before this ships. (1) Is a Design Tool proof with Art Description "Front" and no words acceptable for production, or must Sasha also add the words to the proof description afterwards? (2) The licensing defaults on the saved proof (Student Government Association, Pepperdine University) were not chosen by anyone. If they can be wrong, Sasha must set them, and where they are set in the tool is not yet mapped.
